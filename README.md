# Tiny Oak Lab

The independent Tiny Oak Lab studio site. LookPiko is a featured product. The site uses static HTML, CSS, and a small JavaScript file. The project inquiry form opens the visitor’s email app with a prepared draft.

```powershell
npm.cmd run check
npm.cmd run preview
```

The preview runs at `http://127.0.0.1:4174/`.

## Publish on GitHub Pages

The **Deploy studio website** workflow checks the site and publishes `public/` on pushes to `main`. The repository’s **Settings → Pages** publishing source is **GitHub Actions**.

[Open the studio website](https://hellotinyoaklab-gif.github.io/hello-tinyoaklab/) · [View deployments](https://github.com/hellotinyoaklab-gif/hello-tinyoaklab/actions)

Edit content in `public/index.html` and styles in `public/styles.css`. The public work section uses LookPiko’s existing launch artwork and links. The oak and worktable artwork were created for this site. See `public/assets/licenses/` for font licenses.
